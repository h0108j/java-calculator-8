## ⚙ 기능 목록

### 1️⃣ 문자열 입력

- 구분자와 양수로 구성된 문자열을 입력 받는다.

### 2️⃣ 커스텀 구분자 지정

- 문자열 앞 부분에 `//` 이 존재하는지 확인하고 없다면 3️⃣으로 넘어간다.
- `//`와 `\n` 사이에 있는 모든 문자 각각이 하나의 구분자로 인식된다.
- `\n` 가 문자열에 없는 경우 예외를 발생시킨다.
- 숫자(`0-9`), `:`, `,`, `//`, `\n`는 예약어로 취급하여 커스텀 구분자에 입력되는 경우 예외를 발생시킨다.
- 띄어쓰기 공백은 문자로 인정하나 `//`다음 바로 `\n`이 오는 경우 예외를 발생시킨다.
- `//`부터 `\n`까지를 제외한 문자열을 계산 기능 부분으로 넘긴다.

### 🚫 기재되지 않은 사항 판단

| 조건 | 판단 근거 | 결과 |
| --- | --- | --- |
| `//`과 `\n` 사이에 여러 문자가 있는 경우 | 문자 하나만을 입력 받을 경우 범위를 지정하는 의미가 사라짐 | 범위 내의 모든 문자를 커스텀 구분자 입력으로 받음 |
| 커스텀 구분자가 문자열인 경우 | 커스텀 구분자는 문자(char)임 | 입력은 문자열로 받으나 문자열 각각의 문자가 하나의 구분자로 기능 |
| 음수 입력을 받는 경우 | 입력 조건에서 양수라고 명시하였음 | 커스텀 구분자에 `-`가 포함된 경우 음수를 각각 `-`구분자와 양수로 인식. 이외의 경우 예외 발생 |
| 0을 입력 받는 경우 | 입력 조건에서 양수라고 명시하였음 | 예외 발생 |
| 구분자 사이에 아무것도 없는 경우 | 0으로 취급하려 했으나 0은 양수가 아님 | 예외 발생 |

### 3️⃣ 덧셈 계산

- 입력값을 기본 구분자(`:`, `,`)와 커스텀 구분자를 기준으로 하여 문자열 배열로 나눈다.
- 숫자가 아닌 배열이 있다면 예외를 발생시킨다.
- 각 배열을 정수로 변환하여 덧셈을 진행한다.

### 4️⃣ 결과값 출력

- 덧셈이 완료된 결과값을 `결과 : {숫자}`형식으로 출력한다.
